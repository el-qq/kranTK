# Локальный запуск

Стенд статический: ни базы, ни API, ни переменных окружения в рантайме.
Достаточно отдать браузеру собранные файлы — или вообще один файл.

## Что нужно

[Node.js](https://nodejs.org) **22.12 или новее** — подойдёт и 20.19+
(таково требование Vite 8: `^20.19.0 || >=22.12.0`). Проверить — `node -v`.
Больше ничего: ни Docker, ни Python, ни сети после первой установки
зависимостей. В CI сборка идёт на Node 24.

## Три способа

### 1. Показать стенд — `npm start`

```bash
npm install
npm start
```

Собирает проект и поднимает локальный сервер на
**http://localhost:4173**, открывая браузер. Именно то, что нужно для
демонстрации: страница отдаётся так же, как будет отдаваться на Pages.

Порт закреплён (`--strictPort`): если 4173 занят, команда честно упадёт,
а не уедет молча на другой порт. Освободить порт или поменять его в
`package.json`.

### 2. Разрабатывать — `npm run dev`

```bash
npm run dev
```

Dev-сервер Vite на **http://localhost:5173** с горячей перезагрузкой.
Правки в `src/` применяются мгновенно, состояние экрана по возможности
сохраняется. Для демонстрации не нужен — он медленнее и отдаёт
несобранный код.

### 3. Без сервера — автономный HTML

```bash
npm run build:standalone
```

Кладёт `dist-standalone/kran-monitor.html` (~300 КБ): стили и скрипты
вшиты прямо в страницу, внешних файлов нет. Открывается двойным кликом с
диска, переносится флешкой или письмом.

Почему нельзя просто открыть `dist/index.html`: браузер не грузит внешние
ES-модули с `file://` (CORS для схемы `file:` не работает), и страница
останется пустой. Встроенный в HTML модуль выполняется нормально — на этом
и построен `scripts/make-standalone.mjs`.

Что стоит знать про автономный файл:

- **Шрифты.** Roboto подтягивается с Google Fonts. Без сети текст
  отрисуется системным Arial — на работу и вёрстку это не влияет.
- **Вход.** Признак сессии лежит в `sessionStorage`. Часть браузеров не
  даёт страницам с диска доступ к хранилищу — тогда приложение работает
  в памяти: войти можно, но перезагрузка страницы вернёт форму входа.
- **Ссылки-маршруты.** Хеш-адреса (`…kran-monitor.html#/monitoring/2483580`)
  работают и с диска.

## Запускалки для тех, кто не работает с npm

```bash
./scripts/start.sh      # macOS, Linux
scripts\start.cmd       # Windows
```

Скрипты проверяют наличие и версию Node, при отсутствии `node_modules`
ставят зависимости (`npm ci`, если есть `package-lock.json`) и запускают
`npm start`. На Linux/macOS может потребоваться `chmod +x scripts/start.sh`.

## Если что-то не так

| Симптом                                                      | Причина и что делать                                                                          |
| ------------------------------------------------------------ | --------------------------------------------------------------------------------------------- |
| `command not found: npm`                                     | не установлен Node.js — поставить LTS с nodejs.org                                            |
| `Vite requires Node.js version …`                            | версия Node ниже 20.19 / 22.12 — обновить до актуальной LTS                                   |
| `Port 4173 is already in use`                                | занят порт: закрыть прошлый запуск или поменять порт в `package.json`                         |
| Пустая белая страница при открытии `dist/index.html` с диска | так и должно быть: нужен `npm run build:standalone` (см. выше) или `npm run preview`          |
| Текст выглядит «не тем» шрифтом                              | нет доступа к Google Fonts, подставился Arial                                                 |
| После перезагрузки просит логин снова                        | сессия живёт до закрытия вкладки — это `sessionStorage`, так задумано                         |
| Ошибки типов при сборке                                      | `npm run typecheck` покажет подробности; `noUnusedLocals` включён, лишний импорт валит сборку |

## Проверка перед показом

- [ ] `npm start` открывает стенд, вход `demo` / `demo` работает;
- [ ] на «Мониторинге» хронология играет и перематывается;
- [ ] переключение Live / Архив и листание дат работают;
- [ ] при показе без интернета — заранее собран `build:standalone`.
