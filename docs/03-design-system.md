# Дизайн-система

Все значения перенесены из инлайн-стилей макетов в CSS-переменные:
[`src/styles/tokens.css`](../src/styles/tokens.css). Новых цветов в
компонентах не вводить — брать токен, а если подходящего нет, сначала
добавить его в `tokens.css`.

## Палитра

| Роль             | Токен                        | Значение              |
| ---------------- | ---------------------------- | --------------------- |
| Фон приложения   | `--bg-app`                   | `#eef1f6`             |
| Карточка         | `--surface`                  | `#ffffff`             |
| Граница карточки | `--border`                   | `#dfe5ee`             |
| Основной текст   | `--ink`                      | `#0f172a`             |
| Вторичный текст  | `--ink-4`                    | `#64748b`             |
| Подписи          | `--ink-muted`                | `#94a3b8`             |
| Акцент / ссылки  | `--accent`                   | `#1668c8`             |
| Норма            | `--ok` / `--ok-text`         | `#16a34a` / `#15803d` |
| Предупреждение   | `--warn` / `--warn-text`     | `#d97706` / `#b45309` |
| Перегруз         | `--danger` / `--danger-text` | `#dc2626` / `#b91c1c` |
| Нет связи        | `--neutral`                  | `#94a3b8`             |
| Тёмная навигация | `--nav-bg`                   | `#10243c`             |

Пороговая логика цвета загрузки одна на всё приложение:

```
нет данных → --neutral
> 100 %    → --danger   (перегруз)
≥ 90 %     → --warn     (предупреждение)
иначе      → --ok       (норма)
```

## Типографика

- Основной шрифт — **Roboto** (400 / 500 / 700).
- Все числа, время, координаты и госномера — **Roboto Mono** (класс `.mono`).
  Это не украшение: моноширинный шрифт не даёт цифрам «прыгать», когда
  показатели пересчитываются при движении курсора хронологии.
- Заголовки секций — класс `.eyebrow`: 11 px, uppercase, `letter-spacing .06em`,
  цвет `--ink-muted`.

Размеры: 10–11 px подписи, 12–13 px основной текст, 14–15 px заголовки
карточек, 20–23 px заголовки экранов, 22 px крупные значения-плитки.

## Геометрия

Радиусы `--r-xs` 5 px … `--r-xl` 9 px. Карточки — `--r-xl`, кнопки и поля —
`--r-md`, чипы — `--r-xs`. Ширина навигации — `--nav-w` 92 px.

## Правила компоновки

- Плотная сетка: карточки разделены `12–14 px`, внутри — `12 px`.
- Группы показателей — колонки с разделителем `border-right: 1px solid
var(--border-soft)`; так сделаны «Показатели» и итоги хронологии.
- Раскрывающиеся блоки («Дополнительно») — общий компонент-паттерн:
  заголовок-кнопка с кареткой `▼ / ▲` и телом под ней.
- Недоступные в демо элементы (разделы меню, «Экспорт», «Настройки»)
  не прячутся, а отключаются: `disabled` + пояснение в `title`.

## Что нарисовано, а не подключено

- **Карта** (`src/components/MapPlaceholder.tsx`) — сетка и маркеры вместо
  Яндекс.Карт: стенд статический, ключа и сети у него нет.
- **Техника** (`src/components/CraneGlyph.tsx`) — силуэт крана вместо
  фотографии: фотографий в выгрузке нет, внешние картинки тянуть неоткуда.
- **Схема крана** (`src/features/monitoring/CraneScheme.tsx`) — настоящая
  геометрия: стрела рисуется по углу и длине из точки телеметрии, поэтому
  при перемотке хронологии картинка двигается вместе с числами.

## Адаптив

Стенд рассчитан на монитор, но не разваливается на телефоне. Точки перелома:

| Ширина    | Что меняется                                                                                                                                                                                                        |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ≤ 1320 px | «Обзор» из трёх колонок (загрузка / схема / геометрия) становится одной                                                                                                                                             |
| ≤ 1180 px | на главном экране карта и «Состояние парка» уезжают под список кранов                                                                                                                                               |
| ≤ 900 px  | на экране входа брендовая панель уходит наверх, форма под неё                                                                                                                                                       |
| ≤ 767 px  | телефонная раскладка: боковое меню превращается в верхнюю полосу, список кранов в «Мониторинге» — в горизонтальную ленту, колонки показателей идут друг под другом, плеер хронологии переносит шкалу на свою строку |

Правило, о котором легко забыть: сетки с большим минимумом колонки
(`repeat(auto-fit, minmax(380px, 1fr))`) на узком экране распирают страницу,
потому что колонка не может стать уже минимума. Использовать
`minmax(min(380px, 100%), 1fr)`.

Широкие таблицы («Интервалы работы», «Динамика загрузки») не ужимаются, а
прокручиваются внутри своего контейнера с `overflow-x: auto` — цифры
остаются читаемыми.
