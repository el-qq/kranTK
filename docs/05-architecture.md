# Архитектура приложения

## Стек

Vite 8 + React 19 + TypeScript 7. Ни роутера, ни UI-библиотеки, ни стейт-
менеджера: экранов два, состояние локальное, лишние зависимости в
демо-стенде только мешают.

## Поток данных

```
fleet.ts (якоря)
     │
     ▼
telemetry.getDay(id, дата) ──► DayData { samples, intervals, events }
     │                                      │
     │                                      ▼
     │                          useTimeline(id, дата, диапазон, live)
     │                                      │  курсор во времени
     │                                      ▼
     │                          sample = точка под курсором
     ▼                                      │
aggregate.ts (сводка парка)                 ▼
     │                          OverviewTab / TimelineTab / CraneScheme
     ▼
DashboardPage
```

Ключевая идея «Мониторинга»: **курсор хронологии — состояние страницы**, а
не виджета. `MonitoringPage` держит его через `useTimeline` и раздаёт обеим
вкладкам, поэтому перемотка меняет и полосу, и схему крана, и все
показатели, и список событий.

## Роутинг

Хеш, а не History API: GitHub Pages не умеет rewrite на `index.html`, и при
перезагрузке страницы на пути вроде `/monitoring/2483580` вернулся бы 404.

```
#/dashboard              главный экран
#/monitoring/<id крана>  мониторинг конкретного крана
```

Пустой хеш заменяется на `#/dashboard`.

## Состояние

Только `useState`, ничего глобального:

- `App` — сессия (`useAuth`) и текущий маршрут;
- `DashboardPage` — раскрытые карточки, фильтр, строка поиска;
- `MonitoringPage` — вкладка, режим Live/Архив, дата, диапазон;
- `useTimeline` — положение курсора, воспроизведение, скорость.

## Плеер хронологии (`useTimeline.ts`)

- Диапазоны: `24h` (сутки), `shift` (08:00–20:00), `7d` (неделя).
- Воспроизведение — `requestAnimationFrame`; скорость 1x означает, что вся
  шкала проходится за 60 секунд, 8x — за 7.5.
- Курсор нельзя увести за последние данные; в режиме Live он приклеен к
  последней точке.
- `«` и `»` прыгают к границам интервалов, а не на фиксированный шаг —
  так удобнее разбирать смену.
- Полосу можно тянуть мышью (pointer events) и двигать стрелками ←/→.
